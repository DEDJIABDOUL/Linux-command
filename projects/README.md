# Mini-projets et projet final — planifié

Ce dossier accueillera, dans une phase ultérieure du programme, une série
de mini-projets pratiques (un par domaine couvert dans `01_linux_basics/`
à `26_hpc/`) puis un projet final intégrateur : partir d'une vraie
question biologique, choisir un jeu de données public, l'acquérir, le
documenter, l'analyser de bout en bout avec les outils déjà appris, et
produire un rapport reproductible complet.

Voir `docs/audit_report.md` pour la feuille de route détaillée. Ce
dossier n'est volontairement pas rempli en une seule fois — chaque
mini-projet sera ajouté et validé individuellement, dans le même esprit
incrémental que le reste du dépôt.
