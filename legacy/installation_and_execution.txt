AVERTISSEMENTS CONNUS (détails dans docs/audit_report.md, section 5) :

1. Les versions figées ci-dessous sont anciennes (python=3.7,
   pandas=0.24.0, matplotlib=2.1.2, minimap2 v2.24) et NE DOIVENT PAS
   être réutilisées telles quelles dans un nouvel environnement Conda —
   des versions actuelles devront être vérifiées au moment de la
   réécriture du module concerné.

2. La configuration Conda `conda config --add channels defaults` reflète
   une pratique aujourd'hui déconseillée. Depuis août 2024, la
   documentation officielle Bioconda ne recommande plus le canal
   `defaults` (lié aux conditions d'utilisation d'Anaconda) et préconise
   `conda-forge` + `bioconda` avec `channel_priority strict`, idéalement
   via une distribution Miniforge. Source vérifiée :
   https://bioconda.github.io/ (section « Set up channels »).

3. Le statut de maintenance de LongQC, Porechop et NanoFilt n'a pas
   encore été vérifié via une recherche officielle à la date de ce
   déplacement. Ne pas les présenter comme des outils « modernes » ou
   « recommandés en production » sans cette vérification préalable.

4. Les chemins `/path/to/...` sont des placeholders pédagogiques du
   fichier d'origine — ils devront être remplacés par de vrais chemins
   d'exercice (basés sur l'arborescence `data/raw`, `results/`, etc. du
   module 07_project_organization/) lors de la réécriture.

### GenoBio - Bioinformatics skills training

### Terminal takedown

## Environment setup and configuration

# Bioconda

curl -O https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
sh Miniconda3-latest-Linux-x86_64.sh
exit

conda config --set auto_activate_base false
conda config --add channels defaults
conda config --add channels bioconda
conda config --add channels conda-forge

conda create -y --name python3 python=3.7
conda activate python3

# LongQC

conda install numpy
conda install scipy
conda install matplotlib=2.1.2
conda install scikit-learn
conda install pandas=0.24.0
conda install jinja2
conda install h5py
conda install -c bioconda pysam
conda install -c bioconda edlib
conda install -c bioconda python-edlib

mkdir Bioinformatics && cd Bioinformatics/
git clone https://github.com/yfukasawa/LongQC.git
cd LongQC/minimap2-coverage && make

	# For Mac users:

brew install argp-standalone

# Porechop

cd ../../
git clone https://github.com/rrwick/Porechop.git
cd Porechop && python3 setup.py install

# NanoFilt

cd
pip install nanofilt
pip install nanofilt --upgrade
exit

## Running programs

# LongQC

conda activate python3
mkdir sars-cov-2_test && cd sars-cov-2_test
mkdir SRA
cd
cd Bioinformatics/LongQC/
python longQC.py sampleqc -x ont-rapid -o '/path/to/sars-cov-2_test/1_sars-cov-quality' '/path/to/sars-cov-2_test/SRA/sars-cov-2_SRR18392380.fastq'

#Porechop

cd && mkdir '/path/to/sars-cov-2_test/2_porechop'
porechop -i '/path/to/sars-cov-2_test/SRA/sars-cov-2_SRR18392380.fastq' -o '/path/to/2_porechop/no_adapters.fastq'

#NanoFilt

$ mkdir '/path/to/sars-cov-2_test/3_NanoFilt'
$ NanoFilt -q 7 '/path/to/sars-cov-2_test/2_porechop/no_adapters.fastq' > '/path/to/sars-cov-2_test/3_NanoFilt/Filtered.fastq'

## Troubleshooting : Common errors

	# curl is not found

sudo apt install curl

	# git is missing

sudo apt install git

	# make command is not found

sudo apt install make

	# pip is not installed under python3 environment

sudo apt install python3-pip

	# For a fresh OS installation, certain packages and/or compiling files may be missing, let's fix this with the following:

sudo apt install gcc
sudo apt-get install libz-dev
